# ReportLab PDF Export Service

## Overview

The `reportlab_export.py` module provides a robust, production-quality PDF generation service for DD Consulting project reports. It uses ReportLab Platypus to create professional, widescreen (16:9) PDFs with DD Consulting branding and styling.

## Features

### Design Specifications
- **Page Layout**: 16:9 widescreen/landscape (13.333" × 7.5")
- **Color Palette**: DD Consulting brand colors
  - Navy: `#1B2A47`
  - Steel Blue: `#4A9CC7`
  - Gold: `#C9A84C`
  - Light Background: `#F8FAFC`
  - Dark Text: `#0B1220`

### Document Sections

1. **Header Banner**
   - "DD CONSULTING" title with Navy background
   - "Project Report" subtitle
   - Project name, client name, status, and report date

2. **Metrics Row**
   - Status, Health, Start/End dates
   - Budgeted Hours, Team Load
   - Clean table layout with Steel Blue headers

3. **Executive Summary**
   - Formatted section box with title and content
   - Background shading and borders

4. **Project Objective**
   - Formatted section box
   - Clear typography and spacing

5. **Team Allocations Table**
   - Resource, Role, and Allocation %
   - Professional table styling

6. **Active Risks Table**
   - Risk description, Impact, Probability, Status
   - Gold header for visual distinction

7. **Status Updates**
   - Recent Accomplishments
   - Next Steps
   - Extracted from latest status update

8. **Footer**
   - "Generated by DD Planner • Confidential"
   - Page numbers (Page X of Y)

```python
    project: dict,
    risks: Optional[List[dict]] = None,
    allocations: Optional[List[dict]] = None,
    status_updates: Optional[List[dict]] = None

    """
    Build a professional, widescreen (16:9) project PDF report using ReportLab.

        risks: Optional list of risk dictionaries
        allocations: Optional list of allocation dictionaries
        status_updates: Optional list of status update dictionaries

        bytes: PDF document as bytes
    """
```

### Integration with FastAPI

```python
from fastapi import APIRouter
from fastapi.responses import Response
from services.exports.reportlab_export import build_project_pdf_reportlab

router = APIRouter()

@router.get("/projects/{project_id}/export/reportlab")
async def export_project_reportlab(project_id: str):
    # Fetch project data from database
    project = await get_project(project_id)
    risks = await get_project_risks(project_id)
    allocations = await get_project_allocations(project_id)
    status_updates = await get_project_status_updates(project_id)
    
    # Generate PDF
    pdf_bytes = build_project_pdf_reportlab(
        project=project,
        risks=risks,
        allocations=allocations,
        status_updates=status_updates
    )
    
    # Return as downloadable file
    return Response(
        content=pdf_bytes,
        media_type="application/pdf",
        headers={
            "Content-Disposition": f"attachment; filename=project_{project_id}_report.pdf"
        }
    )
```

## Error Handling

The function implements **three levels of error protection**:

1. **Primary Generation**: Attempts to generate the full PDF with all sections
2. **Fallback Error PDF**: If primary fails, generates a simple PDF with error message
3. **Minimal Valid PDF**: If fallback fails, returns minimal valid PDF bytes

This ensures the function **always returns valid PDF bytes** and never crashes.

```python
try:
    # Primary PDF generation
    return generate_full_pdf()
except Exception as e:
    logger.error(f"Error: {e}")
    try:
        # Fallback error PDF
        return generate_error_pdf(e)
    except Exception:
        # Last resort: minimal valid PDF
        return MINIMAL_VALID_PDF_BYTES
```

4. **Crash-Proof**: Triple-layer error handling ensures reliability
5. **Type Safety**: Type hints and safe converters prevent type errors
